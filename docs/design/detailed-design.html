03 / FLOWCHART · CONFIG

Existing config always wins

Decision flow and failure path: open config migration flowchart. macOS legacy migration: new exists → use new; otherwise legacy exists → copy without overwrite; copy error → stop without generating replacement identity. Neither exists → first-time behavior deferred.

Input/ownership: operator-selected role and path; secret permissions retained. Acceptance: AC-CFG-01–04. Locking and exact legacy paths remain open.

04 / FLOWCHART · SERVICE

Privilege check before system installation

Non-elevated user selects user/system; system without privilege stops and instructs rerun with sudo or elevated Administrator. Root/elevated defaults system; confirmations still apply. Pin the selected user's absolute config and state paths. A privileged process reading user-editable config is an unresolved trust boundary.

Decision view: service installation flowchart. Acceptance: AC-SM-01–04. Account integrity, symlink handling and Windows user-background mechanism are deferred.

05 / SEQUENCE · UDP

Two clients must never exchange replies

Open UDP sequence. Client A and B share a listener, but role runtime maintains distinct logical mappings. Each response is routed to its associated source; datagram boundaries survive. Serve uses a socket per active UDP flow. Endpoint reuse and late responses remain a design risk, not an absolute isolation guarantee. Best effort allows loss, reordering and duplication.

UDP transport, fragmentation, payload limits, timeout and resource policy are deferred until benchmark. AC-UDP-01–04; TCP success/failure and connection reuse are described by TCP sequence and TCP-01–02.

06 / FLOWCHART · UPDATE

Installation ownership selects the update path

Ownership decision · Standalone verification decision

Failed verification retains the old binary absent explicit warned bypass. Running-process consent, alias replacement and Windows atomicity require detailed design. Initial installer defaults to all three binaries; update remains independent. AC-DIST-01–05.
