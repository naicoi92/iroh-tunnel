# Glossary

- **Access**: The tunnel role exposing a local listener and connecting it to a service on a Serve node.
- **Listener**: The local address on which Access accepts traffic.
- **NodeId**: The public identity of an Iroh node, used by Access to identify a Serve peer.
- **Relay**: An Iroh relay used to help establish or carry a connection between nodes.
- **Serve**: The tunnel role running near a target service and accepting connections for it.
- **Service**: A named TCP or UDP forwarding configuration in a role.
- **Target**: The address of the service reached by Serve.
